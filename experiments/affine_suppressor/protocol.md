# Transfer replay on the published calibrated suppressor panel

The source fits and outcomes are already published. This tests transfer of each fitted binary stack into the new native signed-affine tree on a case in which the weaker provider needs a negative weight. The source independently controls whether only the error correlation changes. [Source protocol, generator and results](https://github.com/damiankucharski/FusionBench/blob/62afd107e9ba0bfa0052186acb0e9f687d574822/docs/ensemble-study/calibrated-suppressor/README.md)

Reuse source commit 62afd107e9ba0bfa0052186acb0e9f687d574822, all original banks 41000–41023, correlation 0, .5 or .85, original anonymous provider order and split seeds. Use the same 384 fit rows, 256 validation rows, and independent 8,192-row IID and shift tests as the archived study. Fit public C=1 probability and logit stackers to the original four scaled class-channel features. Convert each to native OKAPI roots with all four scalar inputs, and with only the two positive-class roots by folding complementary coefficients. Freeze every model on fit; zero validation choices. Score the original arithmetic mean, public fit-selected ranked-prefix Top-N, C=1 logit and probability stackers, and the source implementation fit with nonnegative effective logit slopes. Reuse per-bank published comparator losses when anchored against newly replayed controls, labeling them as archived where applicable.

Report maximum row-level probability discrepancy between each native tree and reference, separate by form/transform; 1e-9 is the transfer check. Compare native tree split scores against the source CSV, and record the signed effective slope of the weaker source, mapped back only for analysis after model freezing. For source correlation .85 report native signed-minus-constrained IID and shifted Brier and paired 95% t intervals across 24 independent banks. Report training, transfer and application costs. Replay at least one bank in a fresh process. This is a matched historical validation of the operator on an independent mechanism, not a new estimate of benefit on new data.
