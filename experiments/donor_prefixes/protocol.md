# Operations partway through a value node

This is a **retrospective analysis** of the completed FusionBench semantic-donor experiment. Its original population, training, objective-call budget and primary test remain as registered. Before calculating any panel counts for donor prefixes, we knew the native result on two selected generation-15 populations and had already seen the absence of a productive ordinary crossover in 32 matched populations. A separate constructed example establishes that prefixes can matter in principle. We now ask whether any such building blocks occur in the observed programs. ## Donor definitions

At a native ValueNode, let v₀ be the provider probability. If the value has m sequential operator children, vⱼ is the output of operation j (in recorded child order) applied to the previous v and to its complete ValueNode operands. For each complete recorded source program consider these nested sets of possible donor functions: (1) root output only; (2) completed outputs vₘ of every ValueNode; (3) completed outputs plus every v₀; (4) all of those plus every proper nontrivial intermediate vⱼ, 0<j<m. For (3) and (4), any used prefix denotes a copy of the original value and its first j operations with the same operand descendants. Retain duplicate occurrences within a program only once per semantic function, preserving which recorded source programs supplied them.

An available join takes one donor from each of two distinct source programs and exactly one outer MIN or MAX. Neither source root nor either supplied donor may equal the target. Test equality of full functions on the 16 binary corners, which is sufficient for MIN/MAX on real inputs. Score only strict productive joins with both source operands independent of any previously present target. These are hypothetical joins of available pieces; ordinary subtree exchange has a different move distribution. An archive joins distinct genotypes that were actually scored before the snapshot. Donors may come from different generations in that diagnostic. Preserve every repeated occurrence of a scored program for checking chronology, and reduce identical genotypes only for determining availability.

For all four source sets report live and past evaluated programs separately, generations 1,5,10,15 and both fitted laws. The target is the known population rule on the matched law and the preregistered first population-optimal lattice rule on the additive law. No fit-optimum target selection, retraining or held-out label access is needed. Provide exact source program/prefix evidence for any case where the extended family first becomes productive. Check the first and second source sets against the existing recorded root/subtree joins when comparably defined. Count signed effects using the same fixed banks; zero in these records does not imply future unseen runs are impossible. If no bank exhibits an additional G15 live join, give the one-sided exact 95% upper bound on the probability of at least one hit in a new independent bank's pair of starts.
