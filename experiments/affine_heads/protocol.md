# Can a native OKAPI node reproduce the fitted stacker and improve it with nonlinear input subtrees?

## Representation and fixed comparisons

FusionBench’s binary StackingLR and StackingLogit flatten every provider’s two channels in [negative, positive] order, optionally take logit after symmetric clipping at 1e-6, then learn StandardScaler and L2 logistic regression. Use the public model at C=1, lbfgs, max_iter=2000 with its default tolerance; preserve its output normalization. Add an optional signed binary affine node with intercept to OKAPI and freeze the existing default search palette. For both transforms transfer the trained model into a native Tree without refitting. Test separately (a) both original scalar channels exactly as supplied and (b) one positive-class scalar per provider using binary complement identities. For (a) invert the feature scaling before importing the signed coefficients. For (b) fold each pair of coefficients only after this full two-channel fit. Do not fit a one-channel surrogate with the same C; duplicated standardized coordinates change the relative strength of the regularizer. Primary representation check is maximum absolute positive-class prediction error at most 1e-9 on every split for both transforms. Report any violation and report the observed maximum without rounding it to zero.

## Local fitting and controls

Take 12 new independent data banks 31700–31711 per family for TwoPathways and CorrelatedRedundancy, the established anonymous column permutation across all splits, 384 fit, 256 validation and 4,096 each on fresh IID and published strength/correlation shift. No privileged provider IDs, labels outside fit, validation selection or hyperparameter tuning. Every learned policy has the same 384 fit labels. Include unweighted arithmetic mean, public ranked-prefix Top-N on Brier (all M individual scores and all M balanced prefixes, selected on fit) and the two C=1 public regularized stacks. Also include ordinary native singleton GP at 160 objective calls, with fixed starts 311/751, as a separately budgeted search reference.

Estimate four provider groups by signed Pearson average linkage on the fit predictions. For each of the three partitions of these four groups into two pairs, construct a fixed function max(min(group mean i, group mean j), min(group mean k, group mean l)). Include all three features alongside all original providers. Fit the outer signed affine head just once using the SAME public stacker recipe and both class channels for every original or generated predictor. Import that solution into an actual nested OKAPI tree with positive-only original and subtree roots. Compare against the same affine head on the same native fixed topology initialized with the corresponding flat stack’s coefficients on original providers and zero coefficients for the three added features. Its function is the flat comparator. Record the regularized logistic objective before and after fitting as well as Brier on all four splits. This locally fits the outer node for fixed features. It does not optimize inner subtrees, discover topology by GP or minimize Brier directly.

Prespecify inferred-group and size-preserving shuffled-membership versions (two fixed shuffle starts 311/751 per bank). Both make three identical-shape features, use the same fit rows and learn equally many coefficients. The number of groups and fixed root shape are informed by TwoPathways. The alternate family is a test of possible validation or shift loss when these features are unnecessary. Repeat the whole comparison for probability and logit features separately. The primary predictive contrast is inferred-group augmented logit head minus plain logit stacking on TwoPathways fresh IID. Report unadjusted 95% paired t intervals over 12 bank differences, averaging starts within bank. Public flat stacks and the fixed grouped optimizer are deterministic. Report the interaction vs shuffled control, both families, fit, validation, IID and shift, independent seeds, mean and worst transfer errors, search/fit/construction/time costs and solver iterations separately. Each augmented arm uses three additional label-free fit feature predictions and one supervised fit. Count duplicated structure and list evaluation rows; do not equate a logistic iteration with one GP tree assessment. Freeze all fits before held-out scoring. Split outputs are measured once per frozen model, and no learned selector switches between methods in response to their held-out scores.
