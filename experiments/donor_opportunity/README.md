# When a native crossover can produce a two-path rule

This independent check uses the two prespecified live snapshots at bank 6603, GP seed 821, beginning of generation 15, one each from the matched and additive arms. It traces actual stock crossover for every possible physical draw on those two populations. FusionBench owns the sixteen-bank study, baselines, search trajectories and population estimates. The mechanism here is an offline probability calculation for frozen trees. It scores neither an alternative optimizer nor any unseen labels. [Registered cohort, endpoints and tree grammar](https://github.com/damiankucharski/FusionBench/blob/a694b558f26851a7ad6507e37beb3e8c86e14400/docs/ensemble-study/semantic-donors/protocol.md)

For each pair of possible parents, run native crossover for the allowed node classes and every permitted pair of sites. Evaluate both offspring on all 16 Boolean corners using OKAPI's own value, MIN and MAX nodes. On this lattice grammar the signatures determine the program's function on any real inputs, since a scalar threshold commutes with min and max. Count a productive event only when neither parent already has the target function and at least one child gains it. Each unordered tournament of two distinct contestants has two equiprobable orders. Replaying the native tournament weights the ordered pair of winning parents, including two copies of one individual. The separate uniform-parent comparison preserves physical-swap probabilities. This observer does not infer what the subsequent mutation or survival step would do.

A hand-checkable separate fixture distinguishes three ways in which a birth can fail. Let `P=max(min(A,B),C)`, `Q=min(C,D)` and the goal be `max(min(A,B),min(C,D))`. Among cross-parent swaps only replacing the third value C of P with Q's root (or its reciprocal orientation) produces the goal. With equal population fitness, half the parent draws are mixed, the required node class has probability 1/2, and the required sites have probability 1/3 and 1/2. The resulting stationary probability per crossover is **1/24**. With two unequal fitnesses, a full size-two tournament always picks the better individual and the probability is **0**, although uniform parents still give **1/24**. With a five-node limit, both input parents remain legal but the seven-node target cannot result, giving **0** even with uniform parents. This constructed example explains the distinction between possible parent contents, chances of parent selection and a size cap. [Executable checks](check.py)
