# Can an ordinary GP archive add useful predictors to a signed logistic head?

Prospective comparison on twelve independent, previously unused banks 81400–81411, two GP restarts 233 and 479, and three default binary laws: Committee, TwoPathways and CompositionalSwitch. The first is logit-additive. The other two have interactions. All three use the identical optimizer, operator palette, feature-selection rule and regularization, with anonymous shuffled provider IDs and no supplied group count, target grammar, taxonomy or true probabilities. The older affine-head study supplied three group compositions informed by the generator. The present feature search sees only ordinary GP programs. [Existing head and earlier basis](../affine_heads/README.md) · [Source stock configuration](https://github.com/damiankucharski/FusionBench/blob/d79f228/fusionbench/eval/suite_point_gp.py)

## Rows and controls

Independently draw 384 discovery rows D, 384 head-fitting rows H, 256 validation rows V, 4,096 IID and 4,096 shifted rows per family/bank. Reuse each bank across all methods and restarts. Use default TwoPathways and CompositionalSwitch shifts from the standard suite; Committee's separately specified shift changes its calibrated single-expert accuracy from .75 to .68 while keeping the same provider count. A single random column permutation is fixed for the whole bank. All methods receive float64 complementary binary columns reconstructed from the positive probability, giving the same actual channels to native and public stacking. Never inspect IID or shifted labels to construct or choose features, heads, regularization or an optimizer budget.

The ordinary arithmetic mean, ranked-prefix Top-N (all M prefixes; Brier) and public `StackingLogit(C=1)` train on H as direct controls for the independently fitted head. A second Top-N and public stacker use **D+H+V**, all 1,024 labels available to the hybrid, to measure practical utility under the same total label budget. Also include D+H references for the unselected augmented comparison (768 labeled rows), and the first native best-by-discovery-Brier tree at 600 calls. Compare every method on the same D, H, V, IID and shift rows. Mark metrics on any rows used by that method for fitting or selection.

## Anonymous feature discovery, fitting and selection

1. Run ordinary GP on D only, using the public binary six-operator stock route and native shallow initializer with point mutation off. Count all 600 objective calls, including initial programs and repeated assessments. Collect each distinct nonterminal, complete ValueNode output in every scored program, including the full root. Preserve native subtree input occurrences and first-visit order. No latent information enters this archive.
2. Compute the public clipped logit of every archived candidate on D. Start with the span of an intercept and the raw providers' clipped logits. For up to three steps, residualize both binary discovery labels and each unused candidate against the current span. Select the candidate with greatest absolute inner product with residual labels divided by the norm of that candidate's residual. Ignore numerically zero residuals (less than 1e−9 relative to the original centered scale with floor 1), and break ties within 1e−10 of the best score in original archive order. Add its residual direction to the span. The rule scores every candidate each step, with no extra logistic fits. Save chosen tree structures, node counts, first appearance and whether a proper subprogram occurrence was encountered. The same label vector may guide ordinary GP and feature ranking on D. H and V are disjoint.
3. On H only fit native `fit_stacking_tree` heads with C=1, both complementary class channels per input, the public logit clipping/standardization and unpenalized intercept. Compare original raw providers alone (FLAT), raw plus the selected up to three native subtrees (ARCHIVE), and raw plus the same number of affine projections of those subtrees' logits onto raw provider logits (PROJECTION). Fit projections by least squares on D without labels. They can redistribute direction-specific L2 cost while remaining inside the raw linear function class. Before converting each projection to a probability, rescale its affine coefficients so its logit stays within ±4 over the entire clipped raw-input domain. Positive scaling is removed by the head's standardization. Log the number of features, objective calls, projections, optimizer fits, validation comparisons, timing and model sizes. Confirm independently trained FLAT versus public stack predictions on every split, including numerical error for clipped or saturated outputs.
4. Evaluate ARCHIVE fixed. Separately deploy a validation-selected model (CHOOSE) that takes ARCHIVE only if its V Brier is strictly smaller than FLAT's, otherwise FLAT. This costs precisely two validation assessments. PROJECTION is a diagnostic comparator and is never eligible. The independently fitted heads used by selection remain frozen. Report which one was returned and its costs. Also report the public flat baseline fitted with all development labels.

## Endpoints

Primary interaction endpoint: validation-selected CHOOSE minus FLAT IID positive-channel Brier, equally weighting the two interaction laws. Primary guard: at Committee, the upper paired 95% interval for CHOOSE minus FLAT must be below +.002 Brier to support a practical no-harm claim at this tolerance. A combined success requires both the interaction upper bound below zero and the guard. For practical comparison report CHOOSE minus the full-budget public stack independently. The fixed ARCHIVE vs FLAT and ARCHIVE vs PROJECTION, each individual family, the D/H/V rows, shifts, fit versus test differences and seed variation are prespecified secondary analyses. Average GP restarts within each bank, then compute paired Student t intervals over 12 banks. A finite or inconclusive finding stays in the report. These three purposely selected binary tasks give targeted evidence; a multiclass or full-suite transfer claim would require another test.
