# An exact fit reference for disjoint native paths

Consider 2K anonymous providers on rows with exactly two high endpoint scores. A perfect matching predicts h when these two providers form a matched pair and l otherwise. This oracle is given the matching-family assumption and the complementary endpoints h and l. It learns the pairs from the same fit labels as the comparison algorithms. The public FusionBench protocol separately controls the information in input frequencies, fit labels, growing sample size and evaluation support. [Prospective benchmark](https://github.com/damiankucharski/FusionBench/blob/3f78d8c/docs/ensemble-study/search-regret/matching-compression-protocol.md)

For an observed edge e, predicting h instead of l reduces total squared fit loss by (h−l) times [2n₁(e)−n(e)] when h+l=1. The benefit is additive over candidate edges because the two high coordinates identify exactly one input edge per row. Maximizing the integer sum of these benefits over all perfect matchings gives the empirical Brier optimum within this family. A dynamic program pairs the first unassigned provider with each possible remaining provider, memoizes subproblems, counts all exact ties, and returns the lexicographically first optimum. Solve time is exponential in the number of providers. For the registered 8- and 12-provider reference cases the counts and fit losses are checked with full enumeration. On rows containing more than two high scores the same deployed model still predicts h if any of its edges is active. The two-active fitting argument applies only to two-active training rows.

The matcher compiles directly to a native MIN for each inferred pair and a single variadic MAX for two or more pairs. The receiving GP is never seeded with the resulting tree. Separate tests recompute whole-program predictions and losses for every possible matching (105 and 10,395 candidates), check each tie, and evaluate the compiled models on held-out interior inputs without another fit. [Fit and native conversion](fit.py) · [Independent enumerative tests](test_fit.py)

Edmonds established the classical weighted matching framework and its polyhedral treatment. The small dynamic program here is a direct subset recurrence; the Brier reduction, synthetic conditional law, and native compilation are specific to this OKAPI/FusionBench study. [Edmonds, Maximum matching and a polyhedron with 0,1-vertices (1965)](https://doi.org/10.6028/jres.069B.013)

## Independent benchmark result

The frozen FusionBench campaign checked every one of 256 fits against this solver, including empirical Brier, the lexicographic tie winner and the number of optimal matchings. It ran the inferred native tree on fit, validation and all held-out two-, three- and four-active states. A second verifier independently recovered all 256 minima and tie counts. In the balanced, six-pair design with 16 fit labels, using input frequencies improved conditional excess by .02559 versus the label-conditional posterior. In the uniform-input design the input frequencies have no matching information and the improvement was exactly zero. The structured prior can fail when the label rule is logistic. The compiled posterior over 10,395 trees used 66 ReLU pair units for at most three high inputs. Four high inputs require accounting for overlapping active pairs.
