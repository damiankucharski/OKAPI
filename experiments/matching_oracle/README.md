# An exact fit reference for disjoint native paths

Consider 2K anonymous providers on rows with exactly two high endpoint scores. A perfect matching predicts h when these two providers form a matched pair and l otherwise. This oracle is given the matching-family assumption and the complementary endpoints h and l. It learns the pairs from the same fit labels as the comparison algorithms. The public FusionBench protocol separately controls the information in input frequencies, fit labels, growing sample size and evaluation support. [Prospective benchmark](https://github.com/damiankucharski/FusionBench/blob/3f78d8c/docs/ensemble-study/search-regret/matching-compression-protocol.md)

For an observed edge e, predicting h instead of l reduces total squared fit loss by (h−l) times [2n₁(e)−n(e)] when h+l=1. The benefit is additive over candidate edges because the two high coordinates identify exactly one input edge per row. Maximizing the integer sum of these benefits over all perfect matchings gives the empirical Brier optimum within this family. A dynamic program pairs the first unassigned provider with each possible remaining provider, memoizes subproblems, counts all exact ties, and returns the lexicographically first optimum. Solve time is exponential in the number of providers. For the registered 8- and 12-provider reference cases the counts and fit losses are checked with full enumeration. On rows containing more than two high scores the same deployed model still predicts h if any of its edges is active. The two-active fitting argument applies only to two-active training rows.

The matcher compiles directly to a native MIN for each inferred pair and a single variadic MAX for two or more pairs. The receiving GP is never seeded with the resulting tree. Separate tests recompute whole-program predictions and losses for every possible matching (105 and 10,395 candidates), check each tie, and evaluate the compiled models on held-out interior inputs without another fit. Edmonds established the classical weighted matching framework and its polyhedral treatment. The small dynamic program here is a direct subset recurrence; the Brier reduction, synthetic conditional law, and native compilation are specific to this OKAPI/FusionBench study. [Edmonds, Maximum matching and a polyhedron with 0,1-vertices (1965)](https://doi.org/10.6028/jres.069B.013)
